# QuickChat AI

An AI-powered chat application built using React.js, Vite, Tailwind CSS, and Google Gemini AI.

## Features

- AI Chat using Gemini API
- Modern UI
- Emoji Support
- Responsive Design
- Real-time Chat Experience
- Mobile Friendly

## Tech Stack

- React.js
- JavaScript
- Vite
- Tailwind CSS
- Google Gemini API
- Netlify
- GitHub
